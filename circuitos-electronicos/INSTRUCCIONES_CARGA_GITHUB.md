# Carga manual a GitHub

1. Descomprima el ZIP.
2. Entre a su repositorio en GitHub.
3. Pulse `Add file` → `Upload files`.
4. Abra la carpeta descomprimida.
5. Seleccione TODO el contenido interior, no la carpeta exterior.
6. Arrastre los archivos y carpetas al área de GitHub.
7. Espere a que termine la carga.
8. En `Commit changes` escriba:
   `Inicializar estructura académica del curso`
9. Confirme el commit en `main`.

## GitHub Pages
Después de cargar:
1. `Settings`
2. `Pages`
3. `Deploy from a branch`
4. Branch: `main`
5. Folder: `/ (root)`
6. `Save`
