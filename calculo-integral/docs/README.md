# Documentación de Cálculo Integral

Esta carpeta documentará la evolución del repositorio de la asignatura.

## Criterios de organización

- Los contenidos académicos se distribuyen en tres bloques según el sílabo.
- Cada bloque tendrá un `index.html` y, progresivamente, páginas HTML por tema.
- Los nombres de carpetas y archivos se mantienen en minúsculas y sin espacios cuando sea posible.
- Los recursos de evaluación se mantienen separados de los contenidos de clase.
- La carpeta `calculo-integral/` es independiente de los archivos existentes de Circuitos Electrónicos para Telecomunicaciones.
